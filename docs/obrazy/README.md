# obrazy (screenshots)

The screenshots of [`../instrukcja.md`](../instrukcja.md). The guide has each one as a commented-out line, so it reads well without them. When you add a file, uncomment its line in the guide (`<!-- ![...](obrazy/...) -->` becomes `![...](obrazy/...)`).

Take them in the dev server, in a match thread between two test accounts. A PNG of the thread, about 900 px wide, with no tokens or private names visible.

| File | What to show | How to get it |
|---|---|---|
| `00-info-komenda.png`, `00-info-szablon.png` (both added) | The `/info` command with mode and template filled in, and the bot's reply for One Minute Madness 3.0 | `/info mode:exotic-tournament-3 template:One Minute Madness 3.0` |
| `03-1-...` to `03-8-...` (all added) | The King of h3dm2 roulette: the `/match start` command, the thread created, the start of the thread, the skipped roll, the hero ban list and its autocomplete, the heroes drawn, and the bid with the lobby settings | the use case 2 of the guide |
| `04-1-...` to `04-6-...` (all added) | The Ranked casual game: the choice of the kind of roll, the thread, the start of the thread, the skipped roll, the drawn heroes and `/match status` | the use case 3 of the guide |
| `05-01-...` to `05-13-...` (all added) | A whole match of the Mistrzostwa Polski group phase: the phase choice, the thread, the bans, the trade, the roll, the bids, the lobby settings and `/match status` | the section "Przebieg meczu krok po kroku" of the guide |

Optional extras, if you want a richer guide: the autocomplete of `/ban` (the list of remaining templates), the reply of `/info mode:mp2026`, and the thread of `/match undo` with the agreement.
